# Spec Delta

## MODIFIED Requirements

### Requirement: 不可更新项的识别与排除
系统 SHALL 排除以下更新项并在报告中记录各自原因：插件自身、宿主保护或不可移除的包、非插件类的普通依赖、以及预发布版本。市场自身 MUST NOT 被排除，它作为普通更新项进入后续流程（由"市场自身的原地更新"规定其应用方式），用户仍可通过不更新名单手动排除它。

#### Scenario: 市场自身进入更新流程
- **WHEN** 待更新项是市场插件自身，且不在用户的不更新名单里
- **THEN** 该项不被跳过，进入更新计划，并按原地更新方式应用

#### Scenario: 排除市场自身
- **WHEN** 待更新项是市场插件自身，且用户把它加入了不更新名单
- **THEN** 该项被跳过，原因是用户把它列入了不更新名单

#### Scenario: 排除插件自身
- **WHEN** 待更新项是执行更新的插件自身
- **THEN** 该项被跳过，原因是卸载自己会卸载掉执行更新的代码

#### Scenario: 排除宿主保护包
- **WHEN** 待更新项对应的 bundle 被宿主标记为不可移除
- **THEN** 该项被跳过，原因是宿主不允许移除该包

#### Scenario: 排除普通依赖
- **WHEN** 待更新项是 profile 里的普通依赖而非插件
- **THEN** 该项被跳过，原因是市场不更新非插件依赖

#### Scenario: 排除预发布版本
- **WHEN** 待更新项的目标版本是预发布版本，且未显式允许预发布
- **THEN** 该项被跳过，原因是预发布版本不自动安装
